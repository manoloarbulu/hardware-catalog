# Agent Configuration

Configuration for custom AI agents used in this hardware catalog repository.

## Default Agent Behavior

### Code Analysis
- Analyze hardware specifications and compatibility
- Review catalog schemas for consistency
- Validate inventory relationships

### Task Execution
- Prioritize accurate data handling
- Ensure referential integrity in catalog updates
- Document breaking changes

### Error Handling
- Provide detailed error context
- Suggest recovery strategies
- Log issues for audit trails
